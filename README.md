# Хаха. Знакомства по приколу

Кликабельный прототип приложения для знакомств, где пары подбираются ещё и по чувству юмора.
Открывается и как обычная веб-страница, и как Telegram Mini App.

Живая версия: https://ebalykov.github.io/haha-prototype/

Данные вымышленные: анкеты и фото сгенерированы, переписки заготовлены. Проценты совместимости
считаются по-настоящему из ответов теста на юмор.
